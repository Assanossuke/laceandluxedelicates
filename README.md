# Lace & Luxe Delicates

A responsive, static e-commerce concept website created by JoeTech Solutions.

## Deploy with Cloudflare Pages

1. Open Cloudflare Dashboard → Workers & Pages → Create application → Pages.
2. Choose **Connect to Git** and select `Assanossuke/lace-luxe-delicates-demo`.
3. Select the `main` branch.
4. Framework preset: **None**.
5. Build command: leave blank.
6. Build output directory: `/` (repository root).
7. Save and deploy.

## Demo limitations

This is a front-end concept only. Product names and prices are illustrative. Cart state is browser-only; checkout, M-Pesa/card payments, inventory, and newsletter collection are not connected. Store policy text is draft copy and needs business approval before launch.
